# Description of programs for the data analysis

The current folder contains the code used for the real-data application. The files are described as follows

* `README.md`: this file.
* `step1_newdata.R`: script to prepare the datasets for the cellwise outlier-detection analysis.
* `step2_newdata_model.R`: script to conduct the cellwise outlier detection using the **FuzzyHRT** algorithm.
